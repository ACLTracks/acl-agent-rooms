# Accessibility

The room retains skip links, a labeled live transcript, visible focus styles, keyboard-accessible controls, status announcements, semantic search labeling, and Escape/close paths. The search panel exposes expanded/control relationships, closes with Escape, and restores focus to its trigger. Search results are buttons so context navigation is keyboard reachable. Layout verification targets desktop, tablet, and 390px mobile widths. Motion and sound remain optional preferences.
